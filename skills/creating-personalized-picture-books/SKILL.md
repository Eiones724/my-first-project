# 个性化绘本制作

把个人资料、故事和参考落实为完整绘本与可继续制作的源文件。已有PDF、原画和脚本是起点，保留已认可的成果；用户要求制作时持续完成实际产物。

## 制作主线

1. **锁定本次定制。** 读取现有资料与实际成果，区分旧样书事实和新订单要求。确认年龄、外貌、家庭称谓、场合、家长希望表达的寓意和已知日期；未知生日不猜测。新孩子应重新设计适龄故事与意象，页数和礼物数量由当前需求决定。
2. **先故事，后分页。** 明确孩子的愿望或期待、可见行动、过程变化与情绪回报。每幅图承担一个主要视觉事件，记录相邻页状态和道具去向。姓名意象是文学联想，未经核实不称为字源。
3. **锁定角色与文字模式。** 保持年龄感、脸型、发型、服装轮廓和比例；性别识别不足时整体调整已认可造型。独立排字便于改字；用户要求图文同生时一次生成逐字正文与画面，明确最终文字是像素。延续已选模式。
4. **验证代表页，再完成全书。** 用能覆盖主要人物、动作和文字布局的场景检查效果；已有有效样张时复用，不重复生成。遵循既有授权推进整本，不逐页制造新审批。
5. **逐幅检查并局部返修。** 核对文字、脸、手、动作、礼物及前后页延续。改动按依赖传播到实际受影响页面，保留旧图与成功成果；默认每项最多两轮明确失败后的修正。未知请求先查结果，不自动当失败重发。
6. **交付可复核成品。** 导出所需PDF、源文件和质量报告；数字阅读或有声版本仅在需要时增加。旧质检不自动证明新文件合格。

## 生图与保存

主模型负责故事、视觉分析和工具调度；插画使用环境实际提供的生图能力。用户指定的GPT-6.1型号与图像模型分别记录，不强制切模型，不写死供应商、尺寸或时限，不把自述或文件存在称为适配验证。

编辑前查看本地原图，区分编辑目标、角色参考与布局参考；保留当前选定主题和画风。借鉴布局而不复制示例人物、原文、水印或批注。正文优先落在自然安静背景，不自动铺白色文字栏；标题装饰与笔画清楚分开。

保存原生图、实际提交提示词、引用、来源和目检记录，选定文件归入项目。角色和道具使用稳定标识并引用统一规范，具体动作及状态写在当前页任务中。保留原图及版本，扩大像素不称原生高清。

## 工具与交付边界

已有栅格页图可用下列工具装订与检查；它们不调用图片模型、不维护生产队列、不生成逐字可编辑正文，也不自动证明故事正确或视觉连续。

```sh
python scripts/picture_book.py init --project BOOK_DIR
python scripts/picture_book.py export --project BOOK_DIR
python scripts/text_check.py --project BOOK_DIR
python scripts/picture_book.py check --project BOOK_DIR
```

运行时从技能目录解析脚本路径，项目路径使用绝对路径。已有工程优先用自己的构建入口，不重新init；新工程先填book.json的素材、逐字文案及印厂参数。默认24内页、230mm方形、3mm出血仅是可调整模板。

检查当前页序、裁切、出血、中缝、文字安全、实际PPI、色彩与编辑范围。图内字逐句目检，OCR复核绑定当前图片和文案哈希；长文先精简或调布局，不无限缩字。图内字不宣称精确字号和字体嵌入。跨导出比较使用相同裁切原点和像素网格。

新作按约定交付阅读PDF、顺序单页、内文与封面分件、实际源文件、角色规范及质量报告；局部改稿交付用户所需的新文件、实际修改源与必要记录，不为一次改句补造全套资产。未达300PPI或印厂参数未定时保留印刷阻断，但不妨碍合格的数字阅读文件交付；数字检查不代表印厂签样。依赖见scripts/requirements.txt，工程回归见scripts/test_*.py。真实儿童资料留在私人项目；向外部发布技能或素材须有相应授权。
